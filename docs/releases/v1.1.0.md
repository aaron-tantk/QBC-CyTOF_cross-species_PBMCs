## Included resource and limits

The manuscript-aligned source additions provide portable preparation sources,
saved-label provenance, and routes for reconstructing saved Figure 5 tables
and Figure 6 network summaries. The separately deposited data include
processed fusion assays, matching maps, four trajectory fits, network-support
tables and numerical exports. Download all six derived-data parts and extract
them into one repository-root `data/`; see the
[download and checksum instructions](../../README.md#download-and-verify-saved-data).
Data archives are not GitHub release assets.

The experimental QBC cohort is unstimulated; stimulation-reference analyses
use a separate CyTOF cohort. Computational links do not identify the same
physical cell. Saved source-reference labels remain authoritative; cluster
plurality labels are audits. Network directions are descriptive, not
experimentally validated causal relations.

No matching, clustering, UMAP, trajectory fitting, bootstrap fitting or
permutation testing was rerun for documentation finalization. Historical
validation/provenance receipts remain unchanged and do not describe a new
full-data run. Exact stochastic refits and complete end-to-end reproduction
of every manuscript panel are not guaranteed. See
[reproduction coverage](../reproduction.md) and
[release scope](../release_scope.md).

Code is MIT-licensed. Data and numerical tables are CC BY 4.0, subject to
the original third-party attribution requirements.
